# 奶站列表实现计划

> 使用 subagent-driven-development 分工执行，先核对规格，再审查质量；保持原子提交。

**目标：** 在现有 NaiList 中增加完整奶站列表及个人、管理员维护能力。

**架构：** 奶站与奶群独立存储，复用认证与写入防护。前端 Tab 选择资源，列表、输入与草稿独立封装，后台保留独立页面路由。

**技术栈：** Go、PostgreSQL、React / TypeScript、现有暖黄 CSS、Vitest / Playwright。
