# 奶站列表实现计划

> 使用 subagent-driven-development 分工执行，先核对规格，再审查质量；保持原子提交。

**目标：** 在现有 NaiList 中增加完整奶站列表及个人、管理员维护能力。

**架构：** 奶站与奶群独立存储，复用认证与写入防护。前端 Tab 选择资源，列表、输入与草稿独立封装，后台保留独立页面路由。

**技术栈：** Go、PostgreSQL、React / TypeScript、现有暖黄 CSS、Vitest / Playwright。

## 任务 1：后端（独立边界：internal、migrations）

- [ ] 增加域名与长度规则测试，运行 `go test ./internal/sites` 确认未实现；实现 `Normalize(Input) (Site,error)`，拒绝 URL / IP / 端口并统一大小写。
- [ ] 新增 `migrations/003_sites.sql` 与嵌入；实现 sites Store 的完整列表、按归属保存、软删除和数据库冲突映射。
- [ ] 新增 API 集成测试覆盖 CRUD、授权、CSRF、重复、校验与归属转移；运行新测试确认缺失行为，再补充公开 / 个人 / 管理员路由。
- [ ] 先添加用户删除约束、跨资源统计和并发转移测试，再扩展 admin Store / handlers，保留事务锁顺序与清理统计。
- [ ] 设置专用 `TEST_DATABASE_URL`，运行 `go test ./...` 与 `go vet ./...`，提交 `feat(sites): 添加奶站接口与管理统计`。

## 任务 2：前端（独立边界：web）

- [ ] 新增 `site-input.test.ts` 测试规范化、长度、非法域名和搜索；运行 `pnpm test` 确认缺失实现，再增加 `site-input.ts`。
- [ ] 新增 Site / AdminSite 类型、SiteForm 与资源隔离草稿；复用 / 提取所属账号选择器；保留关闭草稿、撤销、失败不丢输入和成功清理行为。
- [ ] 首页及个人页增加 ListTabs、奶站列表、查询 / 刷新 / 编辑 / 删除；首页 URL 不变、浏览器标题随页面 / Tab 更新、品牌 NaiList、头像菜单管理奶表。
- [ ] 后台加入奶站路由、编辑和归属；所有后台页面使用同款导航，用户管理新增描述。扩展数量和趋势展示。
- [ ] 新增 / 更新 `web/e2e`：Tab 不改 URL、标题、搜索不请求、刷新、HTTPS 输入、草稿与撤销、后台权限 / 转移、320px 无溢出和深色。
- [ ] 运行 `pnpm test`、`pnpm run build`、Prettier；提交 `feat(web): 添加奶站列表与统一管理导航`。
