# 页脚访问统计实现计划

**目标：** 使用一个 Umami 分享链接配置，后端代理汇总，页脚按用户指定格式展示。

**架构：** `internal/traffic` 负责配置解析、Umami 请求与缓存；`internal/server/traffic.go` 输出汇总，HTML 仅注入是否启用。`web/src/TrafficStats.tsx` 负责加载和手动刷新。

**技术栈：** Go 标准库、React / TypeScript、现有 Toast、Go httptest / Playwright。
