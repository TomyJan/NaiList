# 简单管理区实现计划

> **面向 AI 代理的工作者：** 使用 superpowers:subagent-driven-development，按任务实现并分别审查规格及代码质量。

**目标：** 配置管理员可维护全站用户绑定、账号和奶群归属。

**架构：** `.env` 内部账号白名单、独立管理 API 与页面。PostgreSQL 事务保证身份与归属约束，前端复用现有表单、Toast 与深浅色样式。

**技术栈：** Go / pgx / chi、React / TypeScript / Playwright。

---

## 任务 1：后端权限与管理 API

负责文件：`cmd/server/main.go`、新增配置测试、`internal/server/admin.go` 与测试、`internal/admin/store.go` 与测试、必要的账号/会话事务协调、`internal/server/server.go`、`providers.go`、`logging.go`。

- [ ] 先写并运行失败的真实数据库测试：普通账号访问 `/api/admin/users` 为 403；管理员缺 CSRF 写入为 403；最后一个绑定为 409；并发解绑只能成功一次；有效群阻止删除；更新和转移成功/目标不存在/重复号分别验证。
- [ ] 实现 `ADMIN_USER_IDS` 严格正整数解析，GET me 返回 `isAdmin`；全部管理路由服务端鉴权。
- [ ] 事务锁保护解绑、删除及群归属更新，解决 OAuth 途中撤销产生旧账号会话的竞态；所有成功日志在提交之后。
- [ ] 运行 `$env:TEST_DATABASE_URL='postgres://nailist:nailist-local-test@127.0.0.1:55432/nailist?sslmode=disable'; go test ./... -count=1` 和 `go vet ./...`，全部通过后由主代理审查并提交后端。
