# 管理首页设计与实现计划

目标：`/admin` 作为后台默认入口，沿用现有导航、浅绿/深色主题及权限控制。

设计：四张统计卡片（用户、有效奶群、上传用户、学校/单位），下方两张每日新增柱状图，支持最近 7/30 天切换、刷新、日期详情。手机统计两列、图表单列。空数据正常展示零值，失败使用 toast 和重试。

数据：管理员专用 `GET /api/admin/stats`，禁止缓存。单条 SQL 统一快照聚合，不下载用户和奶群全量资料。按北京时间日期统计，补齐最近 30 天；趋势统计现存用户、有效奶群的创建日期，删除数据不计入，明确说明统计口径。不新增历史日志表或图表依赖。
