# 多登录方式与账号绑定

账号使用独立 users.id，群与会话仍关联账号；identities 保存 QQ/OIDC 身份。老 QQ 身份自动迁移，首次原应用登录补全应用 ID，保留账号、群和会话。

支持 QQ 与一个配置的 OIDC。OIDC 通过发现文档、PKCE、nonce 和签名验证登录；仅以 issuer + sub 识别，不通过邮箱合并。QQ 默认 OpenID，可启用 UnionID，缺失时拒绝登录；首次升级用原 OpenID 补充 UnionID，避免产生新账号。

登录按钮选择启用的方式。管理页顶部展示绑定方式及身份昵称，可授权绑定另一种方式。绑定从带 CSRF 的 POST 发起，短期一次性授权流程绑定发起账号和会话。回调发现会话变更或身份被其他账号占用时拒绝，不合并账号，不提供解绑。

配置通过环境变量与 Compose 提供；公开 API 仅返回方式 ID、名称、图标与登录 URL。客户端密钥、token、subject 不公开。

验证覆盖老库迁移、身份登录和永久绑定、并发登录、UnionID 升级、OIDC 签名/nonce/PKCE、会话变化、冲突、深浅色与移动布局。
