# 简单管理区设计

## 目标与范围

由 `.env` 的 `ADMIN_USER_IDS=1,2` 授权内部账号 ID，空值关闭管理区；启动时拒绝无效 ID。普通账号始终无权访问管理 API，前端入口仅用于导航。沿用 Go、PostgreSQL、React/TypeScript、现有样式与 Toast，不增加框架。

## UI / UX

头像菜单为管理员增加「站点管理」。管理区分 `/admin/users`「用户管理」与 `/admin/groups`「奶群管理」，两项胶囊导航始终可见。保留现有导航、页脚、MiSans、浅绿强调色、圆角边框、自动深色。选择独立页面而非塞入个人管理页，避免混淆本人数据与全站数据；不引入大后台侧栏。

桌面一行一个用户或奶群；移动端自然堆叠，不使用横向滚动表格。页头只有标题，搜索框和记录数量。加载、空列表、搜索无结果与失败重试各自明确。保存、失败、解绑、删除结果均使用既有底部 Toast。

用户行显示昵称、内部账号 ID、有效奶群数量、各登录方式名称/稳定标识与身份昵称。身份不暴露 OpenID、UnionID、OIDC subject、token 或客户端密钥。解绑按钮显示在对应绑定旁；仅剩一个绑定时禁用并说明「至少保留一种登录方式」。解绑二次确认，并明确该账号需重新登录。删除用户二次确认；有有效奶群的用户须先在奶群管理转移归属。当前管理员不能删除自己。

奶群行显示学校/单位、关键词、群号、可打开的完整链接、所属用户昵称与 ID；长链接折行。编辑复用四项表单、校验、二维码解析、撤销和草稿，增加可搜索的所属账号选择。保存一次提交四项信息和归属，失败保留输入。归属默认为当前所有者，切换须明确选择真实账号。管理员草稿与个人草稿隔离。

个人绑定区展示自己的账号 ID，便于首次登录后配置管理员。无权限直接打开管理地址显示简短无权限状态；未登录提供登录按钮。

## API 契约

- `GET /api/me` 增加 `isAdmin: boolean`。
- `GET /api/admin/users` 返回数组 `{id,nickname,avatarUrl,groupCount,identities:[{providerId,nickname,avatarUrl}]}`，按 ID 排序。
- `DELETE /api/admin/users/{id}/identities/{provider}` 解绑，成功 204；不存在 404，最后一个绑定 409。
- `DELETE /api/admin/users/{id}` 删除，成功 204；本人或仍有有效奶群 409，不存在 404。
- `GET /api/admin/groups` 返回有效群数组，包含公开的四项信息与管理专用 `ownerId`；保持更新时间倒序，不经过 CDN 公共列表。
- `PUT /api/admin/groups/{id}` 接收 `{organization,keywords,qqNumber,joinUrl,ownerId}`，其中 keywords 与既有输入一致为逗号分隔字符串；返回保存后群含 ownerId。目标不存在 404，群号重复 409，输入无效 400。

所有管理 API 必须先认证、再检查配置白名单；写入沿用来源、CSRF、并发限制。返回 `Cache-Control: no-store`。

## 事务与记录

解绑锁定用户行后检查绑定数量并删除，至少一个绑定的限制在并发请求中仍成立；撤销目标账号全部会话和待完成绑定流程。OAuth 与解绑/删除的并发不能让已撤销身份重新签发旧账号会话。

删除用户锁定目标用户；有有效群即拒绝，历史软删除群可清理，随后删除会话、身份、待绑定流程和账号。归属转移与四项修改在同一事务，确认目标账号存在并协调用户删除锁。成功日志只在提交后输出，带操作管理员、目标账号、群 ID、旧/新所有者、解绑 provider、撤销会话数量；DEBUG 记录主要校验和事务阶段，不记录 OAuth 身份秘密。

## 验收

真实 PostgreSQL 验证未登录/无权限/CSRF、配置解析、最后一个身份保护（含并发）、解绑会话撤销、删除受限及资源清理、群更新/转移与重复号。浏览器覆盖管理员入口、两页搜索、四项编辑与转移、确认/失败保留输入、深浅色和移动端无溢出。运行 Go 测试/vet、前端格式/单测/构建及浏览器回归，按设计、后端、前端、文档拆分提交。
