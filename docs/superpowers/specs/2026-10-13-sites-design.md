# 奶群与奶站列表

已通过交互原型确认；继续开发无需再次确认。原型位于 OpenDesign 项目 nailist-sites-prototype。

- 首页和「管理奶表」采用带图标、黄色下划线的奶群 / 奶站 Tab，首页切换不改变 URL。后台导航采用同款视觉，保留独立路由。品牌统一为 NaiList。
- 浏览器标题为「页面名 - NaiList」，首页随 Tab 更新。首页说明同时覆盖群与站；后台各页面均有标题和描述，用户管理补充描述。
- 奶站字段为站点名称、域名、学校 / 单位，全部必填；站名和单位分别最多 32 个 Unicode 字符。仅接受有效 DNS 域名，不接受端口、IP、凭据和路径。支持中文域名标签，前后端统一转换为小写 Punycode 后校验、保存，中文与 Punycode 写法共享唯一性约束；后缀为至少两位英文字母。
- 输入框外固定显示 https://；粘贴完整链接时去除协议、www.、路径和查询片段，仅保留域名；普通输入也规范化。前后端独立校验，后端拒绝非域名载荷。访问链接固定拼接 https://。
- 中文域名仅在列表、编辑输入框和删除确认中解码显示；提交、后端存储与跳转仍使用 Punycode。公开和后台搜索同时匹配中文与 Punycode。域名输入框下提示「求您也在贵站添加本站友链喵」。添加或编辑发生域名冲突时返回 409，提示「此域名已存在, 请前往首页搜索查看」；由数据库唯一索引保证并发安全。
- 奶站完整加载、本地搜索站名 / 单位 / 域名，客户端随机排序，刷新重新加载和随机，搜索不扰动顺序；个人管理按更新时间倒序。
- 个人可增删改自己的奶站，沿用草稿、撤销、底部 Toast、缓存更新提醒，草稿按资源类型 / 账号 / 作用域隔离。
- 后台新增 /admin/sites，列表展示站名、单位、HTTPS 链接与归属，支持编辑与转移归属。用户列表显示奶站数量，删除账号前必须转移所有有效奶群和奶站。
- 后台统计新增有效奶站和每日新增奶站，贡献者与单位跨两类资源去重，保留用户、奶群趋势与 7/30 天筛选。
- 独立 sites 表和 API，软删除、唯一索引、外键、认证、CSRF、管理员权限与语义化分级日志沿用现有模式。迁移可重复执行且保留全部现有数据。

API：公开 GET /api/sites；个人 GET /api/my/sites，POST /api/sites，PUT /api/sites/{id}，DELETE /api/sites/{id}；管理员 GET /api/admin/sites、PUT /api/admin/sites/{id}。
Site JSON：id、name、domain、organization、updatedAt，管理员额外返回 ownerId。写入 JSON 为 name、domain、organization，管理员额外提供 ownerId。
