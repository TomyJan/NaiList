# 奶龙随机音频

用户已选择方案 1：导航栏品牌旁增加一个小喇叭按钮，所有页面可用；其余 UI 和提示不变。

- 页面完成加载后在空闲时间获取固定 CDN 索引，并以两个并发任务预加载音频，不阻塞列表和登录。
- 索引准备好后按钮可用；点击随机播放一段，音量固定 36%，连续点击替换当前音频，不自动播放、不叠加。
- 优先使用已预加载的 Blob；尚未缓存时直接使用索引中的音频地址。索引和音频错误静默处理，不发 Toast。
- 卸载时中止请求、停止播放、释放 Blob URL；路由切换保留播放器。后端 CSP 只为该 CDN 音频目录及 Blob 播放开放必要权限。
- 验证异步加载、并发上限、随机和音量、连续点击、失败清理，以及深浅色手机布局和实际 CSP。
