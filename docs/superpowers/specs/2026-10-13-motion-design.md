# 全站动效

沿用现有黄色强调色和布局，使用 CSS 与浏览器原生动画，不增加依赖。

- 弹窗：220 ms 淡入、160 ms 退出，遮罩同步渐变。原生 dialog 不做 transform，保证其中 Toast 的视口定位和窄屏布局。关闭时保留原生模态与焦点约束至退出结束，立即禁用内容交互。保存、取消、Esc 和遮罩关闭均适用，草稿规则不变。
- 头像菜单：180 ms 淡入与轻移，160 ms 退出；收起期间不可交互，箭头同步旋转。
- 页面和列表 Tab：220 ms 内容淡入、上移 6 px；导航和 Tab 不等待动画，不修改 URL 规则。首页、管理奶表、管理后台共用滑动强调条，适配宽度和字体变化。
- 刷新：列表、概览及页脚图标每圈 700 ms；请求期间持续转动，快速请求也完成一圈，不人为延迟数据展示。
- 按钮和输入框：颜色、边框和阴影 140 ms 过渡，按钮按下轻微缩放。列表整体入场，不给大量列表逐行添加动画。
- 减少动态效果：关闭位移、旋转和过渡，立即清理退出内容；保留加载状态、焦点和 toast 生命周期。

验证浏览器中的真实退出生命周期、快速开关、草稿保持、快速请求旋转、Tab 切换、减少动态效果、浅深色及移动端布局。
